# 02 Modelos de redes neuronales

**Sesión del módulo:** Sesión 9 (viernes) — Árboles/bosques + redes neuronales (segunda mitad).
**Prerrequisito:** `01 Modelos de árboles y bosques aleatorios` (misma sesión).
**Notas relacionadas:** `main.tex`, capítulo 2, sección "Modelos de redes neuronales" (unidades
neuronales, funciones de activación, preprocesamiento, backpropagation).

## Objetivo de la unidad

Entender la unidad neuronal básica (suma ponderada + función de activación), cómo se organizan
en capas, y ver ese mismo mecanismo aplicado a un problema real de clasificación de imágenes.
